# Aura Studio

মনে কর তুমি একজন web developer এই সেক্টরে তোমার ২০ বছরের অভিজ্ঞতা রয়েছে।
এখন তুমি আমাকে একটি agency website বানিয়ে দাও।  যার সম্পূর্ণ রোড ম্যাপ আমি তোমাকে দিচ্ছি সাথে সাথে তোমাকে কিছু ভিডিও ও  screenshot add করে দিচ্ছি।

১। একটি navbar থাকবে যার বাম পাশে একটি logo থাকবে,  logo টি তোমার মত করে parpel color এর সাথে অন্য color  gradient mixt করে বানিয়ে দিবে।
ডানপাশে menu থাকবে: Home, Our work, services, about,  Blog,  Contact নামে ঠিক যেমনটি Video তে  রয়েছে।

২। hero section এবং body তে যে কন্টেন্ট ও animation  থাকবে সেগুলো  ভিডিওতে ও screenshots এ যেমন দেয়া আছে তেমনই হবে।

৩।  service মেনুতে কয়েকটি submenu  থাকবে : website build, E-commerce website build,
Saas build,  Automation

৪। automation submenu এর আরো কিছু submenu  হবে: Facebook automation,  WhatsApp automation, YouTube automation. Ai assistant

৫। service menu এর  প্রত্যেক মেনুর  আলাদা আলাদা page
থাকবে যেখানে আমার বানালো পোজেক্টগুলো add করতে পারবো

৬। about  menu  তে যে কন্টেন্ট ,  image ও ফিচার  থাকবে তার একটি screenshots add করে দিচ্ছি।

৭। blog মেনুতে যেভাবে post show করবে সেগুলোর একটি screenshot এড করে দিলাম।

৮। একটি admin panel  থাকবে যেখান  থেকে blog post লেখা যাবে project গুলো upload করা যাবে।

৯। একটি perfect blog  post লেখার জন্য যে tool kit গুলো দরকার তার সব গুলো ফিচার সুন্দর করে বানিয়ে দাও।

১০। footer মেনুতে যে icon, content  menu থাকবে সেগুলো screenshots ও ভিডির মত হতে হবে।

১১। cursor টি ও ভিডিওর মত ডিজাইন এর হতে হবে।

মোট কথা ডিজাইন টি হতে হবে নান্দনিক,  অকৃত্রিম,  ও চোখ ধাধানো  সুন্দর ui ডিজাইনের। যেখানে থাকবে parpel কালারের সাথে যায় এমন color gradient এর সংমিশ্রণ। চোখ ধাধানো animation। চমৎকার font
